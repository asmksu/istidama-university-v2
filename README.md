## محتويات الحزمة الكاملة

مجلد `docs` للوثائق بنسخ PDF وMarkdown والصور والقواميس. مجلد `solutions` للتصدير الأصلي غير المعدل **1.1.0.0**. مجلد `source` لكود الواجهات وC# والتدفقات وCustom APIs والخط وأصل ترخيصه. مجلد `dist` للموارد المبنية، و`tools` لتجهيز نسخة بيئة العمل، و`evidence` لنتائج التحقق، و`SHA256SUMS.txt` لفحص الملفات.

آخر Snapshot بتاريخ **17 نوفمبر 2026**: Assembly **1.0.0.15**، و37 جدول مجال، و7 Custom APIs، و86 SDK Steps، وتدفقين سحابيين. يتضمن حذف المستخدم القابل للاستعادة وفحص جاهزية الحساب قبل التفعيل.

## التشغيل والنقل

GitHub يحفظ المصدر والوثائق؛ تشغيل البرنامج يكون داخل بيئة Microsoft Dataverse المرخصة. التخصيصات لا تشمل بيانات الأعمال أو الملفات أو حسابات المستخدمين أو الاتصالات أو التراخيص. اتبع دليل النقل لإعداد بيئتك واتصالات SharePoint والتدفقات والأدوار.

اختبارات النموذج تمت أساساً بحساب إعداد واحد. قبول مستخدمين مستقلين، وعزل الفرق وملفات SharePoint، وإغلاق فجوات التذكير والتصعيد والمشاركة الآلية، مطلوبة قبل الاستخدام الإنتاجي. تجربة الأدوار محاكاة ولا تغير هوية الدخول. تسجيل أي بريد لا ينشئ حساب Microsoft أو ترخيصاً.

الحزمة لا تشمل كلمات مرور أو رموز وصول أو مفتاح التوقيع الخاص. ملف `ARCHIVE_SHA256.txt` يتحقق من الحزمة الكاملة.
